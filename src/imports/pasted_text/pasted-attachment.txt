═══════════════════════════════════════
GLOBAL RULES FOR ALL CONNECTIONS
═══════════════════════════════════════

1. All modals: trigger = On Click, animation = Smart Animate scale 0.96→1 + opacity 0→1, 200ms easeOut. Close = reverse, 150ms easeIn.
2. All "back" navigation (← links): Push Right, 300ms easeOut.
3. All "forward" navigation (→ links, CTAs): Push Left, 300ms easeOut.
4. All dropdown overlays: translateY(-8px)→translateY(0) + opacity 0→1, 200ms easeOut.
5. All page-enter: opacity 0→1, translateY 20px→0, 400ms easeOut. Apply to every new page arrival.
6. Buttons on press (all): scale 0.98, 150ms ease (Smart Animate).
7. Toast notifications: translateX(40px)→translateX(0) + opacity 0→1, 300ms easeOut. Fixed bottom-right.
8. Total minimum connections: 68. Verify count in Figma prototype panel before handover.
